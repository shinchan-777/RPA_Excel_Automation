# 📊 RPA_Excel_Automation (UiPath)

---

## 🚀 Project Overview
This project is an **Excel Automation System built using Robotic Process Automation (RPA)** with UiPath.  
It automates tasks related to Excel such as reading data, processing it, and performing operations automatically.

The project demonstrates how RPA can be used to eliminate manual work in data handling and improve accuracy, speed, and efficiency in business processes.

---

## 🎯 Objectives
- Automate repetitive Excel-based tasks  
- Reduce manual data entry errors  
- Improve data processing speed  
- Demonstrate real-world RPA use case  
- Build scalable automation workflows  

---

## ⚙️ Key Features
- 📥 Reads data from Excel files automatically  
- 🔍 Processes and manipulates data  
- 📊 Performs calculations and transformations  
- 📤 Writes processed data back to Excel  
- 🔁 Handles repetitive data operations  
- ⚡ Improves efficiency and accuracy  

---

## 🛠️ Technologies Used
- **UiPath Studio**  
- **XAML Workflows**  
- **.NET Framework**  
- **Excel Application Scope / Workbook Activities**

## 🔄 Workflow Explanation
1. The automation starts from **Main.xaml**  
2. Opens the Excel file using UiPath Excel activities  
3. Reads data from specified sheets  
4. Processes data based on defined logic  
5. Performs required calculations or transformations  
6. Writes updated data back to Excel
